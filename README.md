# Spotify for Learning 🎙️
Turn any topic into a personalized 5-minute podcast, powered by AI.

## 📌 Project Description
Spotify for Learning is an AI-powered tool that helps users learn on the go by converting custom text prompts into short audio podcasts. 🧠🎧

You type a topic — it generates a script, converts it to audio, and plays it instantly. Supports multiple languages too!

## 🚀 How to Run
Make sure you have Python and Streamlit installed.

```bash
pip install -r requirements.txt
streamlit run main.py
